## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

I used two pointers starting at the beginning and end of the string. The characters are swapped while the pointers move toward the center.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

A single-character string is already reversed, so no swap is needed.
